# ⚡ AsciiBit Hub

> Una utilidad de escritorio moderna, elegante y de grado comercial diseñada para la conversión rápida y precisa de códigos ASCII, caracteres y sistemas de numeración (Binario y Decimal).

## 🚀 Características Principales

* **Módulo ASCII & Caracteres:** 
  * Conversión bidireccional exacta en el rango de **0 a 255** (soporta ASCII estándar y extendido/ANSI).
  * Validación dual mediante controles `NumericUpDown` y `TextBox` optimizados.
* **Módulo de Bases Numéricas:** 
  * Transformación fluida y directa entre valores **Binarios** y **Decimales**.
* **Experiencia de Usuario (UX) Avanzada:**
  * Interfaz modular limpia con barra lateral de navegación intuitiva.
  * Soporte global para la tecla **Enter** en todos los campos de entrada, permitiendo ejecutar conversiones instantáneas sin necesidad de usar el ratón.
* **Recursos Integrados:**
  * Enlace directo incorporado a la referencia oficial de [ASCII Code](https://www.ascii-code.com/) para consulta rápida de tablas completas.
* **Estética Comercial:**
  * Paleta de colores profesional (inspirada en temas oscuros minimalistas) y diseño libre de dependencias externas pesadas.

---

## 🛠️ Arquitectura y Tecnologías
* **Lenguaje:** C# (.NET)
* **Interfaz Gráfica:** Windows Forms (WinForms) con diseño modular basado en contenedores `UserControl`.
* **Patrón:** Separación clara entre la lógica de negocio y las vistas de usuario.
